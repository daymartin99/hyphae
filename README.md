# HYPHAE

A quiet incremental about a network that learns what it is.

**Play: https://daymartin99.github.io/hyphae/**

On a phone, open the link and add it to your home screen (Share → Add to Home
Screen on iOS; the install prompt on Android). After the first visit it plays
fully offline. Your run saves on your own device — closing the tab loses
nothing.

Three acts. It does not explain itself; that is deliberate. No ads, no
accounts, no analytics — one self-contained file.
